SafeZone SA

Community Security & Smart Incident Reporting Platform

SafeZone SA is a community security and smart incident reporting platform designed to provide community members with an accessible method of reporting and tracking safety incidents.

Project
SafeZone SA is being developed as a WIL project for XISD6329.

The system consists of:

- PHP web application
- Android mobile application
- MySQL database
- REST API for communication between the mobile application and database
- Role-based system functionality
- Incident reporting and tracking
- Moderation workflow
- Authority assignment
- Reporting and analytics

Problem Statement
Community members may experience barriers when reporting incidents through traditional reporting channels.

SafeZone SA provides a centralized digital platform where users can submit incidents, track their reports and allow authorized personnel to manage reported incidents.
